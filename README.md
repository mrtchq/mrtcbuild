# MrTC Builds (`mrtc.me`)

React + TypeScript application rewritten for **[mrtc.me](https://mrtc.me)** — *MRTC // T.C. • AI ARCHITECT*.

## Features

- **Interactive 10-Slide Carousel Deck**: Smooth horizontal swipe/scroll deck with keyboard shortcuts (arrows, Home, End), bottom navigation dock, and floating side navigation arrows.
- **The Chunker (Level 1 Boss Fight)**: Interactive task-breaking system with Wall of Awful integrity meter, real-time checklist progress, and breach celebration with confetti.
- **Neuro-Command HUD**: Gamified XP level and rank progression engine (Recruit to Legend), dynamic sound effects toggle, and slide completion progress bar.
- **WebAudio Synthesizer**: Custom sound engine with synth clicks, reward arpeggios, and warp whoosh effects.
- **Living Neural Synapse Canvas & Starfields**: Responsive multi-layer starfield background with parallax motion, synapse node network, action potential pulses, and click ripples.
- **Control Deck System Settings**: User controls for background animations, sound effects, motion parallax, and haptic feedback.
- **Legal Modals & Static Backups**: In-app readable Privacy Policy and Terms of Service.

## Tech Stack

- React 19 + TypeScript
- Vite 6
- WebAudio API
- HTML5 Canvas & CSS3 Animations

## Development

npm run dev
